# ShoppyKart – E-commerce Website 🛍️
ShoppyKart is a modern and responsive e-commerce frontend website designed to provide an attractive online shopping experience. It features product showcases, special discounts, promotional banners, customer testimonials, and a clean user interface.

## 🚀 Features
- Modern homepage design
- Responsive navigation bar
- Promotional hero banner
- Deals of the Day section
- Best Discounts and Special Offers
- Product showcase section
- Promotional shopping banner
- Customer testimonials
- Newsletter subscription section
- Footer with useful links and contact information

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap

## ⚙️ How to Run
1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/shoppykart-ecommerce-website.git
   ```

3. Open the project folder.
4. Run `index.html` in your web browser.
